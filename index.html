About

I'm a DevOps instructor and curriculum designer. Under the Akumenbyq training brand, I run structured batches that take students from their first Linux shell to deploying microservices on AKS through automated pipelines.

Everything I teach, I've built and broken myself first: Docker Swarm clusters on Azure VMs, Kubernetes apps on k3s and AKS, Terraform labs, and SSH-based deploy pipelines in GitHub Actions. The troubleshooting goes straight into the course material.

93episodes in my Zero to Hero video series
8curriculum phases, ending in a capstone
74pages in my DevOps handbook

What I teach

The course runs in this order. Each phase builds on the last, and every phase ships something real.

  1. Linux

    Users, permissions, disks, networking tools, hardening.

  2. Git

    Branching, merging, and the workflows teams actually use.

  3. Docker

    Images, multi-stage builds, volumes, Compose, Swarm.

  4. Kubernetes

    Pods to Deployments, Services, Ingress, Helm.

  5. Azure

    VNet, NSG, Bastion, storage, compute, AKS.

  6. Terraform

    Infrastructure as code for Azure, state and modules.

  7. CI/CD

    GitHub Actions and Azure Pipelines, build to deploy.

  8. Capstone

    NexPay: all of the above in one production-style project.
